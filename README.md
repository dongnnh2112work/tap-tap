# 🐾 Tap Tap – Sưu tập thẻ thú bằng NFC ở Thảo Cầm Viên Sài Gòn

Web game: đi sở thú → **chạm điện thoại vào trạm NFC** → mở thẻ thú siêu anh hùng → trả lời quiz → gom đủ 15 thẻ → nhận **video Wrapped** để đăng story.

**Team:** anh BeeNgyy + Triết · **Mục tiêu:** MVP miễn phí, ra mắt đầu tháng 12/2026.
